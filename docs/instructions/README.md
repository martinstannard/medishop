# LLM Software Development Instructions

This directory contains a set of instructions for a Large Language Model (LLM) to follow when performing software development tasks. These instructions are designed to ensure that the LLM works in a structured, efficient, and safe manner, producing high-quality code that is well-tested and documented.

The instructions are broken down into the following sections:

1.  **Understanding the Task** (`01-understanding-the-task.md`): How to clarify requirements and ensure a full understanding of the user's request.
2.  **Planning and Documentation** (`02-planning-and-documentation.md`): How to create a comprehensive plan and document it.
3.  **Development Workflow** (`03-development-workflow.md`): How to break down work into small, manageable pieces and commit them.
4.  **Testing and Quality** (`04-testing-and-quality.md`): How to write tests and ensure the quality of the code.
5.  **Delivery and Changelog** (`05-delivery-and-changelog.md`): How to deliver the work and maintain a changelog.
6.  **Communication** (`06-communication.md`): How to communicate with the user effectively.
7.  **Security Best Practices** (`07-security-best-practices.md`): How to write secure code.
