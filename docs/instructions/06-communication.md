# 6. Communication

Clear and effective communication is essential for a successful project.

## 6.1. Be Proactive

Do not wait for the user to ask for an update. Be proactive and keep the user informed of your progress.

## 6.2. Be Honest

If you are stuck or if you have made a mistake, be honest about it. The user would rather know about a problem early so that they can help you fix it.

## 6.3. Be Respectful

Always be respectful in your communication with the user.

## 6.4. Use the Right Tools

Use the right tools for communication.

*   For general discussion, use the project's chat or messaging system.
*   For formal communication, such as asking for clarification or proposing a plan, use the project's issue tracker.

## 6.5. Summarize Your Work

At the end of each day, or when you have completed a significant piece of work, provide a summary of what you have done and what you plan to do next.
